# Cashier PRD

## Product Summary

Cashier 是一款面向个人与轻量自用场景的 AI 记账产品。用户可以上传收据图片、输入简短文本，或直接使用快速记账创建消费记录；系统会把原始来源文档与结构化账目关联起来，并提供按账本隔离的查询、筛选与统计能力。

产品的核心目标是把记账成本降到足够低，让用户愿意持续记录，而不是提供专业财务流程。AI 文档解析是异步后台处理；对不需要 AI 的场景，快速记账应当即时完成。产品同时支持服务凭证驱动的 API 接入，方便自动化上传和外部集成。

## Target Users

### 适合

- 想用拍照或一句话完成记账的个人用户
- 需要多账本隔离个人、工作、出差消费的轻量用户
- 需要多币种记录与基础统计，但不想维护复杂报表的人
- 需要通过快捷指令、脚本或服务凭证接入 Cashier 的自动化用户

### 不适合

- 需要专业财务报表、对账、审计流程的会计场景
- 需要多人协作审批或企业级权限体系的团队场景
- 需要银行直连或重 ERP 集成的企业财务系统替代需求

## Core Capabilities

- 认证：支持 OTP 邮箱验证码登录，以及可选的 OIDC/SSO 登录
- 账本：支持多账本隔离、主货币与 AI 偏好设置
- 来源文档：支持图片上传、文本输入、重试、异常确认与状态追踪
- 快速记账：支持无需 AI 解析的手动快速记账，并原子创建来源文档与账目
- 账目明细：支持查看、编辑、删除、筛选与关联原始来源文档
- 分类与币种：支持分类管理、多币种记录与换算后的统计展示
- API 与自动化：支持 service credentials 和 API 访问，用于脚本、快捷指令和外部系统集成
- 统计：支持按时间范围查看消费汇总、分类分布和趋势

## Primary Flows

### 1. AI 解析记账

1. 用户选择账本并上传图片或输入文本
2. 系统创建 source document，并将其置为异步处理状态
3. 后台 AI 任务解析金额、币种、商家、分类与条目
4. 成功时生成结构化账目；异常时保留待用户确认或重试

### 2. 快速记账

1. 用户输入金额、分类和可选描述
2. 系统直接创建手动来源文档与账目
3. 该流程不依赖 AI，提交后立即完成

### 3. 查看与修正

1. 用户在账本中查看来源文档与账目列表
2. 用户可按日期、金额、分类等条件筛选
3. 用户可修正账目、重试来源文档或删除无效记录

### 4. 自动化接入

1. 用户为账本创建 service credential
2. 外部客户端通过 API 提交来源文档或读取账本相关数据
3. API 与 Web 端共享同一套账本隔离和异步处理能力

## Domain Terms

- Ledger：账本。数据隔离和设置配置的顶层单元。
- Source Document：来源文档。用户上传的图片、文本或手动快速记账对应的原始记录。
- Ledger Entry：账目。与来源文档关联的结构化消费记录。
- Quick Entry：快速记账。不经过 AI 解析、即时创建的手动记账流程。
- Service Credential：服务凭证。用于 API 与自动化接入的账本级凭证。
- Anomaly：异常。AI 不能可靠解析、需要用户确认或修正的状态。
